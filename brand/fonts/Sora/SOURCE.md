# Sora source

Sora by Jonathan Barnbrook and Julian Moncada. Original project: https://github.com/sora-xor/sora-font

Downloaded from Google's official font repository at commit `a926665019d3f7f25c8b1212cecbfa871e70de82`:
https://github.com/google/fonts/tree/a926665019d3f7f25c8b1212cecbfa871e70de82/ofl/sora

The unmodified variable font and SIL Open Font License are included here for reproducible outlined wordmarks. The AutoLinky wordmark uses weight 670. Only the linked A and returning L use custom vector geometry in `brand/identity.json`; t, y and the remaining letters use ordinary Sora outlines. The font file itself is unmodified.
